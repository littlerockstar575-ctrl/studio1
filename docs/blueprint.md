# **App Name**: GoalForge: Conquer Your Goals

## Core Features:

- Firebase Authentication: Secure user authentication via Google and email login.
- Goal Setting: Users define personal goals (e.g., weight loss, learning Python), stored in Firestore.
- Daily Challenge Generation: AI tool generates daily, achievable tasks aligned with user goals.
- Coin Rewards System: Award coins for challenge completion; Cloud Functions manages balances in Firestore.
- Friend System and Leaderboard: Users connect with friends, track progress on a leaderboard, with data stored in Firestore.
- Daily Notifications: Scheduled notifications remind users to complete challenges, powered by FCM.
- Gamified Progress Tracking: Visual display of streaks, badges, and level-ups to enhance motivation.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) to evoke a sense of progress and accomplishment.
- Background color: Light blue (#E1F5FE) for a clean, motivational backdrop.
- Accent color: Green (#90EE90) for positive reinforcement and completion cues.
- Body and headline font: 'PT Sans' for a modern and accessible feel.
- Minimalist icons for goal categories, achievements, and friend interactions.
- Clean, tab-based interface for Home, Wallet, Friends, and Settings.
- Subtle animations for challenge completion and coin earnings.
